**Tool:** Claude (Anthropic)
**Use case:** Keeping the FastAPI dev server alive across separate tool invocations
**Output summary:** First attempt used `nohup ... & ` — the process was gone by the next
invocation (background children were not surviving between sandboxed shell calls).
**Human review:** Diagnosed via `ps aux` showing the process absent; switched to `setsid ... &`
which fully detaches the process from the invoking shell's session.
**Verdict:** Rejected the nohup-only approach, replaced with setsid. This is exactly the kind
of "AI tried a shortcut, it didn't actually work, here's the real fix" moment the brief asks
teams to document — recorded here instead of quietly overwritten.

**Tool:** Claude (Anthropic)
**Use case:** Seeding demo users with `@demo.local` email addresses
**Output summary:** Pydantic's `EmailStr` validator rejected `.local` as a reserved/special-use
TLD at signup/login time — a real runtime error, not a hypothetical.
**Human review:** Traced the error message, confirmed it was the email-validator library's
reserved-domain check, switched the demo domain to `@testmail.dev` across the seed script and
generator, reset the affected DB rows, and reran the full seed + smoke test successfully.
**Verdict:** Rejected the `.local` domain choice, corrected. Left this entry rather than
retroactively cleaning the seed data's history, because "the AI picked something that looked
fine and it broke on first real use" is a more honest data point than a suspiciously clean log.

**Tool:** Claude (Anthropic)
**Use case:** Severity badge styling (`SeverityBadge.tsx`)
**Output summary:** First version built Tailwind class names via string interpolation
(`text-severity-${severity}`).
**Human review:** Caught before it shipped, without needing to run the build to notice —
Tailwind's JIT scanner requires literal class strings in source to generate the corresponding
CSS; an interpolated class name would compile without error but silently produce no styling.
**Verdict:** Rejected the interpolated version, replaced with a static lookup map of full class
strings per severity. This is a known, easy-to-miss AI code smell with Tailwind specifically —
worth flagging explicitly for whichever agent picks this repo up next, since it's the kind of
bug that passes `npm run build` cleanly and only shows up as a visual defect.
